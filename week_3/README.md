# Week 3 — Python Programming Fundamentals 🐍

This folder contains all Python learning files for Week 3 of the eMobilis Fullstack Development course.

## Files

| File | Topic |
|------|-------|
| `hello.py` | `print()`, escape characters, f-strings |
| `variables.py` | Variables, naming conventions, scope |
| `datatypes.py` | str, int, float, bool, list, tuple, dict, set, None |
| `operators.py` | Arithmetic, comparison, logical, bitwise, assignment, identity, membership |
| `controlstatement.py` | `if`, `elif`, `else`, nested conditions, ternary, match |
| `loops.py` | `while`, `for`, `break`, `continue`, `pass`, list comprehensions |
| `functions.py` | Functions, default args, `*args`, `**kwargs`, lambda, recursion, scope |
| `excemptionhandling.py` | try/except/else/finally, raising errors, custom exceptions |

## How to Run

```bash
# Make sure you are in the week_3 folder
cd week_3

# Run any file with Python
python hello.py
python variables.py
python datatypes.py
# ...etc
```

> **Note:** `controlstatement.py` and some sections of other files use `input()`, so run them in a terminal (not just a script runner).

## Virtual Environment

A `venv/` folder is included but ignored by Git. To recreate it:

```bash
python3 -m venv venv
source venv/bin/activate   # Mac/Linux
venv\Scripts\activate      # Windows
```
